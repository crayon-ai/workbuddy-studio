# raw/ — Source Corpus

Put the target author's original articles here, one file per piece, in `.md` or `.txt` format.

- Aim for 10+ pieces covering different topics and lengths, so the distilled Writing DNA stays stable
- Keep body text only: strip navigation, ads, comment sections, and reprint notices
- Use recognizable filenames so you can reference them in `_meta/`

Once the corpus is in place, add metadata annotations under `_meta/` as described in Step 2 of SKILL.md.
