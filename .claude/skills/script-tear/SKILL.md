# 爆款素材拆解 Skill

完整读取一篇爆款素材（**正文 + 图片内文字 + 视频逐字稿 + 评论区**），识别赛道、匹配公式、原样提取脚本，把原文归档到原文库、把拆解写入 `<workDir>/structure.md`。

## 核心理念

1. **识别与匹配，不是自由归纳**：结构不由本 skill 发明——工作台内置了一份公式清单（随调用 prompt 给出，每条公式自带固定结构模板）。本 skill 只做三件事：给素材归一个赛道、从清单里选出最命中的一条公式、说明理由。**必须且只能选清单里的一条**，不允许自创结构。
2. **脚本要原样，不要加工**：工作台要的是「这条爆款的原话」——视频给逐字稿全文，图文给正文全文。保留原有分段与换行，不总结、不缩写、不润色、不加批注。
3. **钩子的精髓常不在正文文字里**：小红书图文的钩子多半在封面图上，视频的钩子在口播前 3 秒。所以**图片文字和视频逐字稿是拆解的必备输入**，不是可选项——只看正文文字是拆不准的。

## 两种模式（由调用 prompt 指明）

### 模式 A：原文已存在（复用，禁止重新下载）

prompt 会给出 `<已有原文目录>`。直接用 Read 读取该目录下的 `正文.md`（含图内文字）、`图片/`（如需看原图再逐张 Read）、`逐字稿.md`、`评论.md`，**不要发任何网络请求重新下载**，直接进入识别与匹配。

### 模式 B：全新抓取（抓全量 + 归档到原文库）

prompt 会给出 `<原文库目录>`。把抓到的所有内容归档到该目录：

1. **抓正文**：Bash 执行 curl（带浏览器 UA；若返回乱码/压缩数据，加 `--compressed` 重试）。提取正文文字，存 `<原文库目录>/正文.md`（开头一行标题）。
2. **抓图片并提取图内文字**：从 HTML 里找正文图片 URL（小红书注意 noteDetailMap 里的图片列表），下载到 `<原文库目录>/图片/`。**逐张分析图片**，把图内文字（封面钩子、图卡标题、步骤文字）整理成 `<原文库目录>/图片文字.md`——封面上的一句话钩子往往是整篇最关键的素材。图片分析规范：
   - **先转格式再分析**：B 站/很多平台的图是 webp/avif，直接喂给图片分析工具常报 400「图片输入格式/解析错误」。下载后先用 ffmpeg 或 sips 统一转成 jpg（如 `ffmpeg -i 1.webp 1.jpg`；macOS 也可 `sips -s format jpeg 1.webp --out 1.jpg`），再分析转换后的文件。
   - **单图失败不卡死**：某张图分析报错时，换转换后的格式重试一次；仍失败就跳过这张图、在 `图片文字.md` 里注明「第 N 张图分析失败」，继续处理其余图片。绝不允许编造图内文字，也不允许因单图反复重试拖垮整个任务。
   - 若封面图最终分析失败，识别与匹配照常进行，但在 `structure.md` 的匹配理由里注明「封面图分析失败，判断基于标题与正文」。
3. **视频转逐字稿**（链接是视频/图文含视频时）：
   - 下载视频（探索页面 API 或 yt-dlp，以实际可用为准）；
   - ffmpeg 转音频（`ffmpeg -i 视频.mp4 -vn -ar 16000 -ac 1 音频.wav`）；
   - 本机 **127.0.0.1:2022** 有 WorkBuddy 的 whisper server（OpenAI 兼容接口 `/v1/audio/transcriptions`）。**必须带 `language=zh`**——默认 base 模型中文能力弱，不指定语言会输出英文幻听。音频大时先切分再逐段转写拼接；
   - 逐字稿存 `<原文库目录>/逐字稿.md`。whisper server 未启动则如实说明并跳过该步（不编造）。
4. **抓评论区**：可得范围内尽量抓（热评/高赞/作者回复），存 `<原文库目录>/评论.md`；抓不到就省略，不编造。

## 识别与匹配（两种模式相同）

通读全部素材（正文 + 图内文字 + 逐字稿 + 评论），写 `<workDir>/structure.md`，格式严格照调用 prompt：

- **赛道**：一个词，从内容本身归纳（美食 / 职场 / AI工具 / 旅行 / 穿搭…均可，不设清单）。
- **公式**：调用 prompt 附有公式清单（`- f1｜名称` 一行一条）。对照每条公式的结构特征，选出**最命中的一条**，输出它的 **id**（如 `f5`）。必须且只能选一条；都相像时选最接近的，并在理由里说明取舍。
- **匹配理由**：一句话，对照命中公式的结构特征说清「这篇素材怎么就符合它」，要具体（点出素材里的实际做法），不许空话。
- **脚本**：原样抄录——视频抄逐字稿全文，图文抄正文全文。保留分段换行，不总结、不缩写、不加工、不加批注、不掺入评论区内容。**脚本为空（没抓到有效原文）就不要写 structure.md**，如实说明失败原因。
