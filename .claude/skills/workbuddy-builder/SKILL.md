# 自媒体工作台

从零搭建一个单文件 `自媒体工作台.html`——本地即开即用的自媒体创作工作台。纯前端 + localStorage 持久化，无需后端与服务器，双击即可使用。

## 一、任务与角色

你是一位审美在线的资深前端工程师，用纯原生技术做出"像设计师手绘"的精致界面。面向个人自媒体博主，把"内容生产全流程"做成可视化面板：灵感采集 → 选题管理 → 素材积累 → 爆款拆解 → 标题生成 → 每日待办 → 发布排期 → 发布后复盘。

## 二、技术硬约束（不可违反）

1. **单文件**：只产出 1 个 `.html`，CSS 全在 `<style>`、JS 全在 `<script>`，全部内联。
2. **零依赖零构建**：禁止 React / Vue / Tailwind / jQuery，不依赖 CDN、无 npm / 打包，双击即开。
3. **原生栈**：HTML + CSS + 原生 JS（ES6+、template literal 拼 DOM）。
4. **本地持久化**：`localStorage` 保存选题、素材、笔记、排期、待办、灵感、个人资料。
5. **中文界面**：`lang="zh-CN"`，全部简体中文。
6. **桌面优先**：默认桌面宽屏，提供 ≤1024px、≤860px、≤680px 三档断点。
7. **全新空白工作台（核心约束）**：所有业务数据（灵感 / 选题 / 素材 / 爆款 / 笔记 / 排期 / 待办）初始化为空。**不预填任何示例数据**。每个列表空数据时显示**友好空状态**（一句引导语 + 一个主操作按钮，如"还没有选题，点右上角新建第一个吧 →"）。所有数字（KPI、侧边栏 badge、筛选计数、hero 统计）从数据**动态计算**，初始为 0。**禁止在 HTML 里写死任何业务数字**。
   **描述性文案同样不得写死精确数据或依赖历史数据的表述**（如"已连接 6 个灵感源""基于 32 篇历史爆款""过往爆款"），一律换成第一次使用时的通用引导文案——想象一个刚装好、零数据的用户，这些地方该显示什么就写什么。

## 三、视觉设计系统（「好看」的关键，严格遵循）

整体风格 = **暖奶油底色 × 马卡龙治愈系 × 手账质感**。避免"默认 AI 味"（纯白、蓝色主色、扁平无层次、Inter 字体）。

### 3.2 关键视觉规则

- **字体分工**：正文 `--sans`；**页面大标题、KPI 大数字、评分数字、阶段胶囊**用 `--serif`（宋体），这是质感来源。
- **背景**：`body` 背景 `--cream` 叠加 **三层 radial-gradient**（左上暖橙光、右上粉光、底部绿光，`background-attachment:fixed`），再叠一层极淡 **SVG 噪点纹理**（`feTurbulence`，opacity ≈ .5，pointer-events:none）。整页温润有空气感，绝不是死白。
- **主按钮**：珊瑚橙渐变 `linear-gradient(135deg,#F6A56B,#EF7E4C)`，白字，橙色投影；次按钮薰衣草紫渐变 `linear-gradient(135deg,#B8A8E0,#8474BE)`。
- **卡片**：白底 `--paper`、`--radius`、`--shadow-s`；hover `translateY(-4px)` + 阴影升 `--shadow-l`，且**左侧滑出 4px 彩色竖条**（`::after`，`--cc` 变量控色，hover height 0→100%）。
- **卡片入场**：`@keyframes cardIn`（opacity 0→1、translateY 14px→0，0.5s），按索引 `animation-delay: idx*60ms` 错位出现。
- **圆角胶囊**：标签、按钮、筛选条用 `--pill`；卡片、输入框用 `--radius`/`--radius-s`。
- **彩色标签**：状态标签一律"浅底 + 深字"（如 `coral-bg` 底 + `coral-d` 字），不用纯色块。
- **过渡**：hover/focus 统一 `transition: all .18s~.25s var(--ease)`。
- **选中色**：`::selection` 用珊瑚橙浅底。

## 四、整体布局与侧边栏

```

│  侧边栏    │            主内容区                   │
│  252px    │   （8 个 view 切换显示）              │
│  固定     │                                      │
└───────────┴──────────────────────────────────────┘
```

- **侧边栏** `position:sticky; top:0; height:100vh`，竖向渐变 `#FCF6EC → #F5EBDA`。
  - **品牌区**：圆角方块 Logo（橙渐变 + 五角星 SVG）+ "WorkBuddy" + 副标题"自媒体创作工作台"。
  - **"当前创作库"小卡**：路径 "WorkBuddy/自媒体创作工作台" + "已同步"绿勾。
  - **导航三组 + 一个配置入口**（每组 = 图标 SVG + 文字 + 数字 badge）：
    - `内容选题`：今日灵感 / 选题池 / 素材库
    - `创作辅助技能`：爆款笔记拆解 / 笔记标题生成
    - `发布复盘`：今日待办 / 发布日历 / 笔记复盘
    - **底部独立「AI 配置」项**（齿轮图标 + "AI 配置"，`margin-top:6px`，`onclick="openSettings()"`）——不属于三组导航，无 badge。
  - **badge 从对应数据动态计算**，为 0 时显示 0（或隐藏）。当前项：白底、珊瑚色文字、左侧 3px 竖条、轻投影。
  - **底部吉祥物卡**：渐变粉橙底 + "✦"。文案**从数据动态计算**：`已创作 X 天`（从最早数据日期算天数，初始 0 或 1）+ `已发布 X 篇选题，继续加油呀～`（已发布选题数）。右下角圆形头像位（`assets/avatar.png`，**留空占位**，缺图回退彩色渐变圆）。
- **主区**：8 个 `<section class="view">`，默认 `display:none`，加 `.active` 显示 + 淡入上移动画。点击侧边栏切换，同步 `location.hash`，刷新回原视图。内容区外层 `.scroll > .wrap` 提供滚动与最大宽度。
- **统一页面头部 `.page-hd`**：眉头标签（胶囊带色 + 可选闪烁 live 圆点）+ 宋体大标题（关键词 `<em>` 珊瑚色）+ 副标题 + 右侧操作按钮/日期芯片。

## 五、八个页面详解（核心）

每个页面 = 头部 + KPI/筛选 + 内容网格。以下逐页说明。

### 页面 1 · 今日灵感（默认首页）

**头部**：眉头带闪烁 live 圆点 + "灵感雷达 · 每日自动抓取创作热点"（**不写"已连接 N 个灵感源"这类数量**）；标题"今日**灵感**，都在这儿了"；副标题"基于当前关键词，自动抓取可溯源热点，并直接生成可转化的创作选题"（**不写"基于 N 篇历史爆款"**）；右侧**日期芯片**（当前日期数字 + 周几）+ "刷新灵感"按钮（**为 disabled 态**，`opacity:.5`，title="个性化推荐（二期实现）"）。

**Hero 欢迎区**（渐变奶油粉橙底，圆角 22px）：
- 左 116px 圆形头像位（光晕 + 闪烁五角星 `@keyframes twinkle`）——**点击打开个人资料弹窗**（`onclick="openProfile()"`），头像 `assets/avatar.png` 留空占位，缺图回退彩色渐变圆。
- 中：问候语 `<span id="heroGreet">下午好呀</span>，<span id="heroUser">创作者</span> 👋`（昵称来自个人资料，缺省"创作者"）+ 宋体大字主文案。**主文案与统计数字随灵感数据动态变化**：有灵感时"今天为你抓到了 **N 条新灵感**，其中 **N 条**和你的风格**高度匹配** ✨"；灵感为空换成空态引导（高亮词珊瑚色 + 白色高光底）。
- 三个磨砂统计卡：今日新增 / 高匹配（匹配度 ≥85）/ 已转选题 —— **全部动态，初始 0**。

**"灵感怎么来"两栏卡片**（**无平台筛选条**）：
- 左卡"按我的笔记刷新"：珊瑚图标 + "每日自动" tag + 说明（**通用描述：基于当前选题与素材标签自动抓取，不写"过往爆款/历史数据"**）+ "刷新个性化灵感"按钮（**disabled，二期实现**）。
- 右卡"输入关键词主动抓取"：紫色图标 + "主动探索" tag + 关键词输入框 + 珊瑚"抓取热点"按钮 + **时间筛选**（24h / 7天 / 30天，胶囊）。抓取动作用 toast 提示（见第八节）。

**灵感卡片网格（2 列 `#inspGrid`）**，每张：
- 头部：平台色点 + 平台名 + 作者 + 发布时间 + 状态标签（"✦ 新灵感"蜂蜜黄 / "✓ 已转选题"抹茶绿 / "★ 已存素材"薰衣草紫）。
- 标题（粗体）+ 内容摘要。
- **绿色"为什么推荐你写"区块**：圆角浅绿底，3 条理由，每条前绿勾圆点。
- **四维评分条**（2×2）：热度 / 新颖 / 匹配 / 可写性，每条 = 标签 + 渐变进度条（`MC1→MC2` 马卡龙渐变）+ 分数。
- 底部按钮：珊瑚"转为选题" / 紫"存为素材" / 灰"忽略"。左竖条 `--cc` 区分。

### 页面 2 · 选题池

**头部**："内容选题"眉头 + 标题"选题**池**" + 珊瑚"新建选题"按钮。副标题"每个选题都是一个创作项目：从灵感、初稿、定稿，到图文卡片和发布"。

**KPI 四卡**（宋体大数字 + 彩色图标 + 趋势小字）：选题总数 / 推进中 / 来源灵感 / 已发布 —— **从 `TOPICS` 动态计算，初始 0**（趋势小字在数据为 0 时隐藏）。

**阶段筛选条**（`.fpill`）：全部 / 初稿 / 定稿 / 图文 / 已发布。

**选题卡片网格（2 列）**，每张：
- 头部：阶段状态标签 + 类型标识（📝图文 / 📺视频 / ✍️文本）+ 右侧更新时间。
- 标题 + 创作角度摘要。
- **阶段流程条 `.flow`**（关键组件）：一排小圆点 + 标签 + 连线。已完成：绿实心圆 + 白勾；当前：白底珊瑚描边 + 光晕 + 中心珊瑚点；未到：灰描边；连线已完成段变绿。**三类型流程不同**：图文 = 灵感→初稿→定稿→图文→发布（5 步）；文本 = 灵感→初稿→定稿→校对→发布（5 步）；视频 = 灵感→大纲→脚本→拍摄→剪辑→发布（6 步）。
- 底部：珊瑚胶囊"查看选题素材 **N**" + 右侧"继续推进"（末步显示"查看数据"）。

**交互**：「继续推进」stage+1、存 localStorage、刷新流程条、若该阶段是今日待办则自动勾选完成；「查看选题素材」弹窗列出关联素材（平台色头像 + 标题 + 平台·日期 + 跳转箭头）；「新建选题」录入弹窗字段 = 选题标题(必填)/创作角度(下拉：观点立意/方法教程/测评横评/入门教程/经验复盘/清单盘点)/主要创作方向/目标读者/发布形式(单选 chip：图文/视频/文本)/发布平台(多选 chip：小红书/公众号/B站/抖音/视频号/YouTube)/预期发布日期(date)，提交后 unshift 进列表、更新 badge、跳转选题池；「灵感转选题」从灵感卡打开，预填标题/角度/来源。

### 页面 3 · 素材库

**头部**："内容选题"眉头（抹茶色）+ 标题"素材**库**" + "添加素材链接"按钮（toast 提示）。副标题"收藏别人的优质内容作为创作养分——AI 自动摘要、提炼值得学习的点"。

**KPI 四卡**：收藏素材 / 覆盖平台 / 已拆解 / 待拆解 —— **从 `MATS` 动态计算，初始 0**。

素材库不设平台筛选条，`#matGrid` 直接渲染全部素材。

**素材卡片网格（2 列）**，每张：
- 顶部：圆形彩色头像（平台色 + 作者首字）+ 作者名 + 平台·日期 + 右侧 👍点赞 / ⭐收藏。
- 标题。
- **AI 摘要块**：紫"AI 摘要"小标 + 摘要正文（浅灰底圆角）。
- **"值得学习的点"**：抹茶小标 + 绿勾列表（3 条）。
- 底部：珊瑚胶囊"查看原文 ↗" + "爆款拆解" + 紫"关联选题"。整卡可点跳原文。

**交互**：「关联选题」弹窗下拉选选题，提交后把素材索引 push 进选题 `mats[]`（去重），同步到"查看选题素材"。

### 页面 4 · 爆款笔记拆解

**头部**："创作辅助技能"眉头（薰衣草紫）+ 标题"爆款笔记**拆解**"。

**URL 录入区**（紫色虚线框，薰衣草浅底）：图标 + "粘贴小红书笔记链接，一键拆解" + 输入框 + 紫"开始拆解"按钮 + 提示文字（支持图文/视频，自动提取封面、数据、正文结构、高赞评论）。动作用 toast 提示。

**已拆解卡片网格（2 列 `#hitGrid`）**，每张：
- 笔记标题。
- 四指标横排（宋体大数字 + 标签）：点赞 / 收藏 / 评论 / 阅读，分别珊瑚/抹茶/紫/蜂蜜色。
- **结构拆解 5 行 `.struct-row`**：每行 = 彩色小标签 + 说明。配色：标题公式(珊瑚)/开头钩子(蜂蜜)/核心痛点(玫瑰)/情绪路径(紫)/心理机制(抹茶)。
- **"可借鉴点"**：珊瑚浅底块 + 一句话。
- 底部：来源 + 珊瑚"下载报告"按钮（toast 提示）。

### 页面 5 · 笔记标题生成

**头部**："创作辅助技能"眉头 + 标题"笔记标题**生成**"。副标题"输入主题，生成多角度标题并打分，告别'标题想半小时'"（**不写"基于过往爆款的标题风格"**）。

**双 Tab 输入区**：
- Tab 1「📝 输入选题 / 方向」：输入框（默认"素材库比灵感更重要"）+ 珊瑚"生成标题"。
- Tab 2「📁 读取本地文件」：虚线"选择本地稿子"按钮（accept .md/.txt）+ 文件名 + "根据正文生成"，FileReader 读正文。

**生成结果（单列大行卡片 `#titleGrid`）**，每个标题卡：
- 左 46px 圆形**评分徽章**（按分数取马卡龙色，白字宋体）。
- 中：标题（粗）+ 一行"心理机制标签（emoji + 机制名彩色胶囊）+ 选择理由"。
- 右复制按钮（复制 + toast）。hover 向右轻移。

> 标题**模板公式即时生成**（不预存标题库）：基于输入主题词套爆款公式（"数字+痛点""反常识纠错""如何/为什么+悬念""身份共鸣+损失规避"等），每个给 80~95 评分 + 心理机制标签，按分数降序。生成时 toast"已生成 5 个标题 ✨"。

**今日待办区**（标题带计数），每条 `.todo-card`：
- 左 5px 彩色竖条 + 26px 复选框。

## 七、交互与状态管理

1. **视图切换** `switchView(name)`：去所有 `.view.active` → 给目标加 `active` → 同步侧边栏高亮 → 写 `location.hash` → 关弹窗 → 滚到顶。监听 `hashchange`。
2. **持久化**：`saveState()` 存 `{topics, notes, calTasks, doneToday}`；`loadState()` 启动还原（用 `splice` 原地替换数组保证引用一致）。灵感/素材/爆款各自 load/save 独立 key。
3. **统一 toast** `toast(msg)`：底部居中胶囊，2.2s 淡出。所有"未实现动作"用 toast，不用 alert。
4. **弹窗**：`.modal-mask`（半透明 + 毛玻璃模糊）+ `.modal`（白底大圆角，scale + 上移入场）。点遮罩或 ✕ 关闭。
5. **筛选条**：`.fpill` 点击切 `.active` 并重渲染对应网格。
6. **初始化**：`renderInsp(); renderTopic(); renderMat(); renderHit(); genTitles(); renderToday(); renderCal(); renderReview();`。支持 URL 深链：`?new` 开新建选题、`?tf` 开转选题、`?mat=N` 开某选题素材。
7. **个人资料**：`openProfile()` 弹窗——头像 `pickAvatar(input)` 用 FileReader 读 base64 存 `wb_avatar`、昵称存 `wb_user`（`maxlength=16`）；保存后刷新 hero 头像、heroUser、侧栏头像。hero 与侧栏头像均 `onclick="openProfile()"`，缺图回退彩色渐变圆。
8. **AI 配置**：`openSettings()` 弹窗——三厂商 radio（智谱 GLM「国内直连·便宜·推荐」/ Claude 官方「最高质量·需翻墙」/ 自定义兼容端点「DeepSeek+router、Kimi 等」）+ API Key（password 输入）+ Base URL（自定义时才显示，`cfgProvSync()` 切换）+ "测试连接" + "保存配置"。本地单文件版仅实现界面与交互，保存和测试连接用 toast 提示即可，不接真实后端。
