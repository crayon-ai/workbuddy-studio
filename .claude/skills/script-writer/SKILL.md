# 内容脚本写作 Skill

参考给定的素材脚本，学它的情绪、结构、爆点，把用户的口水话组织成一段可直接口播/写大纲的内容脚本，写入 `<workDir>/script.md`。**只用 Write 工具落盘，不需要其他任何工具。**

## 怎么用参考素材脚本（先读）

- 参考脚本是学习对象，不是抄写对象。从里面学三样：
  - **情绪**：语感、态度、温度（吐槽 / 真诚分享 / 热血…），让改写后的脚本带上同款情绪；
  - **结构**：怎么开场留人、怎么推进节奏、怎么收尾引互动；段数与节奏以「最适合用户这段内容」为准，不必逐段硬套；
  - **爆点**：数字反差、金句、悬念、提问、扣字互动这类钩子手法，在合适的位置用上。
- 参考脚本里的具体内容、例子、数字是别人的成果，禁止搬进脚本。

## 怎么对待用户的口水话

- 口水话是内容的唯一来源：所有事实、观点、细节只能来自它，你的工作是「组织表达」，不是「补充事实」。
- 缺关键信息（价格/天数/数据…）就在文中写 `【补：需要什么】` 占位，让用户自己填。**禁止编造。**
- 保持口水话原本的语感，像人说话；按「风格」设定调整语气，不要 AI 腔。

## 写作要求

- 产出要能直接用：口播 = 说得出口的句子；图文大纲 = 可直接排版的短段。
- 「时长」是字数预算参考：30 秒≈100 字、60 秒≈200 字，按内容需要分配。

## 产物格式（照调用 prompt 的约定）

`## 标题` 一行标题；`## 正文` 是完整一篇脚本——像正常人写脚本一样自然成文：按内容自然分段、用空行控制节奏，不要 ①②③/数字编号，不要「段名」「套用」这类小标题和批注，不要 markdown 记号。
