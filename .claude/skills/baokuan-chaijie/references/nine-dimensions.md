# 九维度拆解 — 详细写法与话术库

每个维度不只描述"是什么"，要提炼"可复用的公式/模板"。

## 1. 标题为什么吸引人？
先判定标题类型，再拆要素，最后给公式。

常见标题类型：
- **SEO 关键词型**：主题词 + 新手 + 入门 + 指南（吃搜索长尾流量，不靠标题党）
- **反共识纠错型**：`别再[大众默认做法]：先[正确做法]`（制造被纠错焦虑）
- **承诺/工具型**：`[自制/独家] + [一键] + [最好用的结果]`（门槛归零 + 强利益）
- **认知反差型**：`[目标人群]竟然不知道[X]`（制造"我错过了"的紧张感）

给出「标题公式」，说明杀伤力来源（认知缺口 / 精准匹配 / 省力信号）。

## 2. 开头用了什么钩子？
命名钩子类型，逐条拆机制：
- 踩坑故事钩（具体到"天"的细节，英雄之旅微叙事）
- 转变金句钩（"我的第一步变了"，观点先行）
- 量化干货钩（"全文X字|Y分钟"，数字锚定价值）
- 认知反差钩 / 数字权威钩 / 身份赋能钩 / 代劳互惠钩

区分：故事型钩子卖情绪、慢热；金句型钩子卖认知、快节奏。

## 3. 正文结构是什么？
用代码块画结构骨架（分段 + 每段作用）。指出：
- 是叙事型（英雄之旅：困境→顿悟→解药）还是体系型（教科书编号）
- 爆点/高潮在第几段，前面如何蓄势
- 开篇定义 + 结尾升华是否形成认知闭环

## 4. 击中了用户哪些痛点？
表格：`| 痛点 | 文中如何戳/解决 |`。区分浅层痛点（花钱、看不懂）、深层痛点（"我不适合"身份焦虑）、未来痛点（维护、失控）。最后点出**核心痛点**。

## 5. 调动了什么情绪？
画情绪曲线。最常见的是「先压后抬」：
```
【压】焦虑/挫败/自我怀疑
【抬】顿悟→惊喜→掌控→赋能
【升华】归属感/时代感
```
总结情绪配方，并注明是否刻意回避"恐吓式营销"。教程型内容特殊：情绪是「平稳获得感」，不需要强起伏。

## 6. 用了哪些心理机制？
表格对应原文。常用清单：
- 损失厌恶（不用=亏/浪费时间）
- 社会认同（star数/用户数背书）
- 锚定效应（数字/类比锚定价值）
- 身份升级（"你已经是开发者了"）
- 互惠触发（免费分享换点赞收藏）
- 承诺一致性（先收藏的小承诺）
- 峰终定律（金句收尾）
- 完整性偏误 / 收藏即拥有（教程型收藏率高的核心）
- 反共识/纠错心理（否定旧习惯制造缺口）

## 7. 哪些地方制造了收藏/转发欲？
分别列收藏触发点与转发触发点。规律：
- 收藏驱动 = 方法论 + 清单 + 操作步骤 + 可复制模板（"以后用得上"）
- 转发驱动 = 金句 + 惊人事实 + 类比（"别人也该知道"）
提炼「收藏钩子公式」。注意教程型「高收藏低互动」是结构特征，不是缺陷。

## 8. 最值得复用的结构是什么？
给 🏆 黄金模板（一行公式）+ 3 条核心原则 + 次级技巧。例如：
- 「踩坑故事→顿悟反转→方法论升华→工具登场→实证演示→资源链接」叙事弧
- 「SEO标题 + 量化封面 + 教科书分章 + 工具推荐 + 升华结尾」百科模板
- 「反共识纠错标题 + 转变金句 + 痛点 + 可复制模板 + 认知升华 + 代劳CTA」

## 9. 迁移到用户账号可以变成哪些选题？
分 A/B/C/D 类给可裂变选题清单（复刻模板 / 复用标题公式 / 复用举例法 / 复用升华收尾）。每类给 3-5 个具体选题标题。

## 一句话总结
点破本质："它不卖X，它卖Y。" 给出最大启示。
