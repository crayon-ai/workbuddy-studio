# 小红书标题生成（心理机制驱动）

根据用户输入的内容，从 10 种心理触发机制中匹配最合适的机制，生成 5 个候选标题。生成后对每个标题进行去 AI 味检查，确保标题像真人写的一样自然。

## 工作流程

```
用户输入（笔记内容/选题/方向）
  → 提取核心信息
  → 匹配 1-2 种心理机制
  → 参考机制词库 + 案例 + 用户内容 → 生成 5 个候选标题
  → 去 AI 味检查 → 修正每个标题
  → 输出（每个标题 ≤20 字，附机制 + 理由）
```

## 必读参考

生成标题前，先读取 `爆款标题心理触发机制.md`，获取 10 种机制的完整定义：

| # | 机制 | 一句话 | 核心动作 |
|---|------|--------|---------|
| 1 | 好奇 | 你知道 80%，缺关键 20% | 点击 |
| 2 | 捷径 | 反直觉方法，轻松拿大结果 | 点击+收藏 |
| 3 | 从众 | 别人都在冲，我不能落后 | 下单+转发 |
| 4 | 避坑 | 怕吃亏+怕晚+信说真话的人 | 收藏+关注 |
| 5 | 共愤 | 替你说出憋着的话 | 评论+关注 |
| 6 | 治愈 | 被理解的温柔角落 | 收藏+关注 |
| 7 | 幽默 | 无害违和让人笑 | 转发+点赞 |
| 8 | 希望 | 看到那个未来的自己 | 收藏+转发 |
| 9 | 态度 | 借标题宣告我的价值观 | 转发+评论 |
| 10 | 清单 | 帮你筛好了，直接抄 | 收藏 |

## 硬性约束

- 所有候选标题 **≤ 20 个中文字符**（数字、英文、标点、emoji 也计入）。
- 每次生成 **恰好 5 个** 候选标题。
- 每个标题必须标注使用的心理机制和选择理由。
- 每个标题 **必须通过去 AI 味检查**（见步骤 4）。

## 详细流程

### 1. 提取核心信息

从用户输入中提取：

- **主题**：这篇笔记在讲什么。
- **目标读者**：写给谁看。
- **内容类型**：教程、经验、避坑、测评、观点、种草、清单、故事、吐槽、治愈、其他。
- **核心价值**：用户看完能得到什么（方法？避坑？共鸣？希望？消遣？）。
- **语气倾向**：实用、真实、情绪化、观点鲜明、温柔、搞笑、反叛。

### 2. 匹配心理机制

根据提取的信息，从 10 种机制中匹配 1-2 种。匹配逻辑：

**按内容类型：**
- 教程/方法/工具 → 优先「清单」或「捷径」
- 避坑/测评/消费决策 → 优先「避坑」或「共愤」
- 经验复盘/个人成长 → 优先「希望」或「好奇」
- 观点/态度/价值观 → 优先「态度」或「避坑」
- 种草/好物/探店 → 优先「从众」或「清单」
- 吐槽/维权/热点 → 优先「共愤」或「避坑」
- 治愈/生活/宠物 → 优先「治愈」或「希望」
- 搞笑/日常/恋爱 → 优先「幽默」或「共愤」
- 干货/知识/内幕 → 优先「好奇」或「清单」
- 变美/变瘦/逆袭 → 优先「希望」或「捷径」

**按期望动作：**
- 想让人点击 → 好奇、捷径
- 想让人收藏 → 清单、希望、治愈
- 想让人转发 → 态度、幽默、从众
- 想让人评论 → 共愤、避坑
- 想让人下单 → 从众、避坑（先劝退再推荐）

**机制叠加**：一个标题用一种机制做主角，可以叠一种机制做配角。参考 `爆款标题心理触发机制.md` 中每个机制的「常用词库」和「案例参考」获取叠加启发。

### 3. 生成候选标题

对每个候选标题：

1. 从匹配的机制中提取「常用词库」，选取 1-2 个触发词。
2. 参考机制的「案例参考」获取表达节奏感，但**不直接替换关键词套用**。
3. 结合用户内容的具体信息填充。
4. 检查是否 ≤ 20 字。

5 个候选标题应覆盖不同的机制组合或表达角度，不要 5 个都是同一套路。

### 4. 去 AI 味检查

生成 5 个候选标题后，逐条检查以下 8 条规则。命中任意一条，必须修正后再输出。

**规则 1：去掉模板拼凑感**

AI 容易把多个模板零件强行塞进一个标题，读起来像 checklist 组装出来的。真人写的标题通常是**一个自然的念头流出来**，不是一个公式填出来的。

```
❌ AI 味：3个方法轻松搞定XX，新手必看！别再踩坑了！
   → 问题：数字模板 + 轻松搞定 + 人群标签 + 踩坑警告，四块模板硬拼
✅ 自然：XX 搞不定？试试这招
✅ 自然：我踩了 3 次坑才学会的 XX 方法
```

**规则 2：打破完整句结构**

AI 倾向于写完整、工整、语法完美的句子。真人小红书标题经常是**碎片、感叹、半句话、一个念头**。

```
❌ AI 味：这个方法可以帮助你快速提升写作能力
✅ 自然：写作慢？这个方法救了我
❌ AI 味：这是我经过多次尝试后发现的最高效的学习方法
✅ 自然：试了无数种，就这个方法管用
```

**规则 3：压缩 AI 常用词**

以下词汇本身没问题，但 AI 会机械性地使用它们。当标题出现这些词时，问自己：**真人在这种情境下会选这个词吗？**

AI 高频词（需警惕）：深入、关键、核心、必备、搞定、轻松、提升、打造、揭秘、解锁、分享、推荐、必看、建议、究竟、到底、背后

```
❌ AI 味：揭秘XX背后的底层逻辑，建议收藏
❌ AI 味：深入解读XX的核心方法，轻松搞定
✅ 自然：XX 的真相：没那么复杂
✅ 自然：我这样 XX，效果很直接
```

**规则 4：口语感 > 书面感**

小红书标题是朋友聊天式的，不是论文标题。用短词、用生活里的说法。

```
❌ AI 味：有效提升工作效率的 5 个关键策略
✅ 自然：不想加班？练这 5 个习惯
❌ AI 味：如何选择适合自己的护肤品
✅ 自然：护肤品别乱买，先看这个
```

**规则 5：不要为了凑数字硬加数字**

清单型标题的数字要有真实内容支撑。数字不是装饰品。

```
❌ AI 味：改变人生的 3 个习惯（内容里其实列了 4-5 个）
❌ AI 味：一定要知道的 5 件事（正文根本没说 5 件事）
✅ 自然：改掉这个习惯，效率翻了一倍
✅ 自然：我坚持了一年的 3 个习惯（正文真的列了 3 个）
```

**规则 6：慎用符号装饰**

AI 喜欢用冒号分段、破折号停顿、感叹号强调。真人用得少且随意。

```
❌ AI 味：效率提升：3个你必须知道的方法！建议收藏！
   → 冒号 + 数字 + 感叹 + 感叹，符号过度
✅ 自然：效率翻倍的 3 个方法，很实用
✅ 自然：这个提高效率的方法我怎么没早发现
```

**规则 7：允许不完美**

真人写的标题常有语序倒装、口语省略、甚至轻微的"不通顺"。这种不完美反而是人味。

```
❌ AI 味：自律的人都会做的 5 件事
✅ 自然：自律的人，都有这 5 个习惯
❌ AI 味：这个方法让我的收入在短时间内得到了快速提升
✅ 自然：我就是靠这个方法把收入翻倍的
```

**规则 8：有观点，不只是报道**

标题里要有"我"的感受和判断，而不是中立的"这里有一个方法"。

```
❌ AI 味：适合新手的写作方法分享
✅ 自然：我试过最笨但最有用的写作方法
❌ AI 味：推荐几部好看的高分电影
✅ 自然：这几部电影，看完好几天没缓过来
```

### 5. 输出格式

```markdown
## 候选标题

**1. [标题]**
- 心理机制：[机制名称]
- 选择理由：[为什么这个机制适合这篇内容，一句话]
- 去AI味优化：[改了哪里，如"把书面词'提升'换成口语'翻倍'"、"去掉冒号分段，改逗号"；如本来就很自然，写"无，原始生成已自然"]

**2. [标题]**
- 心理机制：[机制名称]
- 选择理由：[一句话]
- 去AI味优化：[改了哪里 / 无]

**3. [标题]**
- 心理机制：[机制名称] + [机制名称]
- 选择理由：[一句话]
- 去AI味优化：[改了哪里 / 无]

**4. [标题]**
- 心理机制：[机制名称]
- 选择理由：[一句话]
- 去AI味优化：[改了哪里 / 无]

**5. [标题]**
- 心理机制：[机制名称] + [机制名称]
- 选择理由：[一句话]
- 去AI味优化：[改了哪里 / 无]
```

去 AI 味优化的写法要求：
- 具体指出改了什么地方（原文 → 改后），例如"把'轻松搞定'换成'不用愁'"。
- 如果标题原始生成就已经很自然、没有触发任何 AI 味规则，写"无，原始生成已自然"。
- 不要笼统写"去掉了 AI 味"或"优化了表达"——必须说清楚改了什么。

## 注意事项

- 机制是帮用户表达内容，不是帮用户包装内容。内容本身没有「希望感」，不要硬套「希望」。
- 每个标题必须和用户内容强相关——不能生成与内容无关的通用标题。
- 案例仅供参考表达节奏，**禁止直接替换关键词照搬**。
- 如果用户输入过于模糊（只有一句话方向），先追问再生成，不要猜。
- 去 AI 味的最高标准：**大声读一遍，像不像朋友发给你的一句话？** 不像就改。
