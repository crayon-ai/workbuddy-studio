# 爆款脚本创作（脚本工坊）设计

日期：2026-09-05
状态：已实现（3.0 第二个功能，commit 待提交）
交互原型：仓库外层 `爆款脚本demo.html`（用户已确认的界面形态）

## 背景与目标

工作台原有链路：灵感 → 选题/素材 → 标题生成 → 复盘/发布，**中间的创作环节缺失**。新增「爆款脚本创作」栏目补齐：

1. 选题下的每条素材可 **AI 拆解**出爆款结构脚本（归纳式，见下）；
2. 用户倒入口水话 + 方向（风格/形式/时长），勾选参考结构，**生成**带爆款基因的自己的脚本；
3. 脚本按选题/账号隔离保存，可复制、查看、删除。

参考了外部工作台的「②脚本」模块（选公式→填口水话→生成→复制），本设计的关键差异：**公式不是手工维护的模板，而是从选题素材的拆解结果自动提炼**。

## 核心机制：归纳式拆解（用户确认的关键决策）

- 拆解 = AI 读素材原文 → **先判定这篇内容的真实结构类型与段数** → 按实际结构输出每段（段名/手法/批注/原文摘录）+ 一句话提炼公式。
- **不套固定模板**：三段式只是最常见结果。清单体（N 个并列点）、两段式（无 CTA）、故事型（起承转合）等按内容归纳；段名也从内容起（如「钩子·痛点+数字」「清单点 1」「起/承/转/合」）。
- 结构散乱的素材标「无明确结构」，不进参考池。
- 生成时以所选参考结构的段数与节奏为骨架；未勾参考用通用三段式兜底。

### 多媒体抓取与原文复用（2026-09-05 追加，用户提出）

- **拆解输入是全量内容**：正文文字 + 图片内文字（封面钩子常在图上，Read 逐张读图提取）+ 视频逐字稿（本机 2022 端口 whisper server，`/v1/audio/transcriptions`，**必须带 language=zh**，base 模型不指定语言会英文幻听）+ 评论区。只看正文文字拆不准钩子。
- **原文库**：`data/accounts/<账号>/sources/<sha1(url)>/`——script-tear 抓到的正文/图片文字/逐字稿/评论归档于此，同 url 再拆（重新拆解）直接复用不重抓。
- **跨链路复用**：同一素材若已做过「爆款笔记拆解」，复用其已下载的 `爆款原文/`，不再重复下载；两链路各自独立分析（九维度报告 vs 结构提取）。查找优先级：前端传的 `reuseTaskId`（HITS 的 url→taskId 映射，覆盖旧任务）→ `teardowns/index.json`（teardown 完成时记录 url→taskId）→ sources 原文库。命中后 prompt 进入「模式 A：复用已有原文」（禁止联网），未命中走「模式 B：全新抓取」。

## 生成逻辑（用户确认）

- **参考 = 骨架 + 写法，口水话 = 唯一内容来源**。prompt 四块：角色任务 / 骨架（主参考段数+每段职责+写法示范）/ 内容原料（口水话+方向）/ 护栏。
- 第一个勾选的参考是**主参考**（决定段数骨架），其余为辅参考（只提取手法）。
- 时长 → 字数预算（30s≈100 字、60s≈200 字）。
- 缺信息处输出 `【补：…】` 占位，**禁止编造**（与拆解模块同一理念）；写法示范禁止搬用内容。

## 前端

- 侧边栏「创作辅助技能」组新增 **爆款脚本创作**（data-view="script"，badge=各选题脚本总数）。
- `v-script` 视图：顶部选题条（chips：选题名+阶段+脚本数）→ 左栏素材脚本库 / 右栏生成器（口水话 textarea + 风格/形式/时长分段选择器 + 参考 pills）+ 生成结果 + 我的脚本库。
- 素材来源：**复用选题已有的 `t.mats` 关联**（索引指向 MATS），「＋ 从素材库关联」弹窗增删。
- 数据（按账号命名空间 `wb:<id>:script`）：`{cur, topics:{[tid]:{mouth,style,form,len,refs[url],scripts[],runningTear,runningGen}}, tears:{[matUrl]:{struct,segs,formula,at}}}`——拆解按素材 **url** 记键（不受素材索引漂移影响）。
- 轮询：`ksPoll`（2s/次，15 分钟超时），timer 存 `_ksPolls`，`stopAllPolling` 统一清理；`ksResumePolls` 在启动与切账号后恢复进行中任务。
- 选题池卡片新增「✍️ 写脚本」按钮 → `openScriptFor(idx)` 直达并锁定选题。
- 备份：`ACC_SUFFIXES` 加入 `'script'`，v2 备份自动含脚本工坊数据。

## 已知边界

- 拆解依赖素材可抓取正文：小红书等平台反爬可能导致失败（如实报错，与爆款拆解同现状）。
- 生成质量依赖口水话信息量；缺信息会以【补：…】占位。
- 「手动微调」当前引导复制到外部编辑器（站内富编辑器留作 3.x 迭代）。
