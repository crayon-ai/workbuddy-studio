# 待办事项页周视图设计

日期：2026-08-25
状态：已确认（草图 v2 review 通过）

## 需求

「今日待办」页升级为「待办事项」页：保留今日视图原样，新增周视图（周一~周日）。周视图参考 Notion 截图的内容组织（顶部统计 + 按选题分组任务卡），用工作台马卡龙风格。数据统一来自发布日历的排期（CAL_TASKS）。

## 页面结构

- 侧边栏菜单项「今日待办」→「待办事项」；badge 仍为今日待办数
- 页头：标题改「待办事项」，ph-actions 右侧按钮前加「今日 / 本周」胶囊切换（复用 .vswitch 样式），偏好存 localStorage（wb_todo_view）
- 今日视图：现有内容原样（今日待办/今日已办两段 + 添加今日待办按钮）
- 周视图：标题区下方渲染，替换今日两段

## 周视图内容

### 顶部 KPI（4 卡，同 .kpi 样式）

| KPI | 口径 |
|---|---|
| 已发布/提醒发布 `x/y` | 本周排期里阶段名=「发布」的任务：x=已完成数，y=总数 |
| 阶段完成 `x/y` + 完成率 | 本周所有排期任务：x=已完成（calTaskDone），y=总数；副文本 n% 完成率 |
| 涉及内容 | 本周有排期且未删除的选题数 |
| 待推进阶段 | y-x（未完成数） |

### 按选题分组卡片

- 数据：本周一~周日（ISO 周一起始）内 CAL_TASKS 的所有排期任务；选题已删的丢弃
- 每选题一卡：左边框选题色（t.cc），头部=阶段状态标签（复用 fl.cls/txt）+ 类型标签 + 标题 + 选题整体进度%（stage/(steps-1)）
- 卡内任务行：勾选圈 + 阶段名 + 图标（stageIcon）+ 选题分类 + 日期（`周X MM.DD`）
  - 日期高亮：今天=橙色胶囊「今天 · 周X MM.DD」；已过期未完成=粉色文字
- **行排序**：未完成在前（按日期升序）；已完成分组沉底（「✓ 本周已完成」小标题）
- **已完成行**：绿色实心勾 + 划线置灰
- **卡片排序**：本周未全部完成的在前（按最近待办日期升序）；全部完成的沉底 + 半透明（opacity .5 + saturate .55，同选题池 topic-done）

### 交互

- 点空勾选圈 → 复用现有 confirmTodo 弹窗确认 → DONE_TODAY 标记 → 周视图+今日视图刷新
- 点已完成勾 → toggleTodo 取消
- 周视图勾选只影响当天（DONE_TODAY 语义不变：非今天的任务勾选时视为当日完成标记）

## 实现要点

1. HTML：#v-note 页头改文案 + 加切换；今日两段包进 `<div id="todayPane">`；新增 `<div id="weekPane" style="display:none">`（KPI 容器 + 分组列表容器）
2. JS：
   - `renderWeekView()`：算本周一~周日 → 汇总任务 → 分组 → 渲染 KPI + 卡片
   - `setTodoView(v)`：切 panes + localStorage + badge 口径不变
   - renderToday/advanceTopic/toggleTodo/submitTodoDone 等改动后同步调 renderWeekView（若周视图激活）
   - 周起止：`mondayOf(new Date())` 工具函数
3. CSS：.week-card/.week-row/.week-done-hd 等少量新样式，放「今日待办」样式区

## 验收

- 切换记忆：进页面按上次偏好显示今日/本周
- KPI 数字与卡片勾选联动实时刷新
- 勾选走确认弹窗；取消勾选恢复；今日视图与周视图数据一致
- 已完成行分组上置、整卡完成沉底变淡
- 今日视图行为与改动前完全一致

- 跨周导航（只看本周）
- 周视图添加待办（顶部按钮仍只加今日）
