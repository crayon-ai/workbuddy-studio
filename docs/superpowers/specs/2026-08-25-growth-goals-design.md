# 账号运营目标页设计

日期：2026-08-25
状态：已确认（草图 review + 4 决策点确认）

## 需求

新增「运营目标」页面：
1. 粉丝目标：设目标值+截止日，手动记录当前粉丝数，历史记录画增长追踪曲线（参考图：渐变面积+目标虚线，**全宽**）
2. 变现目标：设目标金额+周期，录入收入流水（商单笔记/带货收入/咨询收入/平台激励/其他），只看明细列表，**不做曲线**

已否决/调整：
- 粉丝数自动抓取——取消（小红书免登录反爬拿不到），只手动记录
- 收入增长曲线——取消，只要流水明细

## 数据模型（localStorage key：`wb_goals`）

```json
{
  "fans": {"target": 5000, "due": "2026-08-31", "records": [{"d": "2026-08-12", "n": 3200}, ...]},
  "income": {"target": 10000, "due": "2026-08-31", "records": [{"d": "2026-08-24", "type": "brand", "title": "品牌A商单", "amt": 2000}, ...]}
}
```

- fans.records 按日期升序存（同日重复记录覆盖）
- income.records 倒序展示

## UI 结构（#v-goal，侧边栏「发布复盘」分组下加「运营目标」）

1. **页头**：标题「运营目标」+ 副文案 + 右侧「录入收入 +」按钮
2. **目标卡 x2**（grid 2 列）：
   - 粉丝卡：当前值（最新记录）大数字、目标 tag、进度条（当前/目标）、还差多少、距截止天数、今日较上条记录的增量；按钮「✏️ 记录粉丝数」（弹窗填数字）
   - 变现卡：累计收入大数字、目标 tag、进度条、还差多少、笔数、类型汇总小标签；同款按钮「⚙」编辑目标
3. **粉丝增长追踪图**：全宽卡片，纯 SVG 面积折线图
   - x 轴=记录日期（自适应刻度），y 轴自动量程（min-max 加 padding）
   - 目标线=红色虚线（若目标在量程内）
   - 渐变填充（coral）、终点圆点+数值标注、起止日期
   - 无记录/仅 1 条记录时显示空态引导文案；1 条记录画目标线+单点
4. **收入流水**：全宽列表（类型图标+名称+日期+金额），倒序，可删除单条；类型 tag 五种（brand/deal/consult/bonus/other）
5. **弹窗 x3**：设置目标（粉丝/收入共用一个表单：数值+截止日）、记录粉丝数、录入收入（类型 chip + 金额 + 备注 + 日期默认今天）

## 图表实现要点

- 纯 SVG 字符串拼接，零依赖；viewBox 按容器比例 `0 0 1000 240`，`width:100%`
- 折线：折线段连接（不做平滑曲线，数据点少时平滑会误导）
- 量程：records min/max；目标 > max 时量程扩到目标*1.02（目标线画在顶部）
- y 轴参考线 3 条（浅色）+ 数值标签

## 验收

- 设目标、记粉丝数、录收入、删流水全部可用且持久化
- 曲线全宽自适应；目标线/终点标注/起止日期正确；单条记录与空态不报错
- 收入类型汇总与流水一致；进度条/还差数值正确
- 今日增量 = 最新记录 - 上一条记录（仅当最新记录是今天时显示）

## 不做的事（YAGNI）

- 粉丝数自动抓取
- 收入曲线
- 多账号/多平台
- 目标达成历史（达成后可手动改新目标）
