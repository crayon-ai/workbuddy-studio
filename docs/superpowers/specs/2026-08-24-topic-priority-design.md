# 选题优先级属性 + 阶段/优先级双下拉筛选 设计

日期：2026-08-24
状态：已确认（终端问答澄清，直接实现）

## 需求

1. 选题新增「优先级」属性：创建时可选，展示时以颜色区分
2. 选题池筛选改为两个下拉框：阶段 + 优先级，默认均为「全部」，条件取交集（AND）
3. 两个下拉**替代**现有阶段筛选 pill 排（不共存）

## 数据层

- `TOPICS[].priority`：`'high' | 'mid' | 'low'`
- `loadState` 老数据自动补 `priority='mid'`（无迁移脚本）
- 新建选题默认「中」（mid）

## UI

### 创建/编辑表单

- 「创作角度」下拉下方新增「优先级」chip 三选一：🔴 高（coral）/ 🟡 中（honey，默认）/ 🟢 低（matcha）
- `submitTopic` 写入 `priority` 字段

### 展示（卡片 + 表格两视图同步）

- 卡片视图：头部加小色块标签（高=珊瑚红/中=蜂蜜黄/低=灰绿），与阶段标签并排
- 表格视图：「状态」列后新增「优先级」列，同样式
- 点标签弹出高/中/低三项小菜单，点击即改即存（saveState + 两视图刷新）
- 配色用现有 CSS 变量：`--coral` / `--honey` / `--matcha`

### 筛选

- 删除现有 `#topicFilters` 内的 pill 排
- 换成两个下拉：阶段（全部/灵感/初稿/定稿/图文/已发布）+ 优先级（全部/高/中/低）
- 阶段口径沿用原 pill：选中档 = `stage` 等于映射编号（all→不过滤，灵感→0，初稿→1，定稿→2，图文→3，已发布→4）
- 视图切换按钮保持在筛选行右侧不动

## 不做的事（YAGNI）

- 按优先级排序、拖拽改优先级、优先级 KPI 统计
- 优先级筛选的 URL 参数化

## 验收

- 新建选题可选优先级，默认中；老选题显示「中」
- 卡片/表格都能看到色块标签，点击可改，改后两视图与筛选结果同步
- 两个下拉独立筛选、同时筛选取交集，默认全部
- 原 pill 移除后无残留引用
